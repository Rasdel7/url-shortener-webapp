# URL Shortener & Link Analytics 🔗

Shorten URLs, generate QR codes and
track link performance with click analytics.

## Live Demo
[Click here](https://url-shortener-webapp-e9bdyjzd286hsk6fbysk3f.streamlit.app)

## Features
- Shorten any URL with custom or auto codes
- QR code generation with download
- Click tracking and analytics dashboard
- Label and organize all your links
- Delete links you no longer need
- Standalone QR generator for any URL

## Tools Used
- Python, Streamlit, qrcode, Pandas, Matplotlib

## How to Run Locally
pip install streamlit pandas matplotlib qrcode Pillow
streamlit run app.py
